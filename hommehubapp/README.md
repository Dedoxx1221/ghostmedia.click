# HommeHub App — PV2 estática

Este pacote contém a página de vendas do HommeHub App em HTML, CSS e JavaScript locais. A página pode ser hospedada em `public_html`, `www`, `htdocs` ou qualquer serviço de hospedagem estática sem Node.js, React ou banco de dados.

## Arquivos

A página principal é `index.html`. As páginas complementares são `about.html`, `mission.html`, `services.html`, `terms.html`, `privacy.html`, `refund.html` e `contact.html`. Os arquivos compartilhados estão em `assets/styles.css` e `assets/script.js`.

## Hospedagem

Envie todos os arquivos e a pasta `assets` para a pasta pública do seu domínio, mantendo a mesma estrutura. O arquivo inicial do domínio deve ser `index.html`.

Todos os botões de compra usam diretamente o checkout Stripe fornecido: `https://buy.stripe.com/8x23cpg7I87j5sGforfAc00`. A página de contato mantém o placeholder `[EMAIL DE SUPPORT]` porque nenhum e-mail real foi informado.
